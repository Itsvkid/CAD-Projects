# Parametric Gearbox Family Generator

**Programmatic CAD design for engine accessory gearbox scaling**

## Overview

Generate parametric gearbox designs that scale with engine size. One Python script creates gearboxes for 5-50 kW engines automatically.

### Features

✅ **Parametric Scaling** — Power rating determines all dimensions  
✅ **Gear Tooth Profile** — AGMA standard involute teeth  
✅ **Bearing Sizing** — Auto-select bearings for load  
✅ **Housing Design** — Ribbed aluminum casting  
✅ **BOM Generation** — Parts list with supplier info  

## Aerospace Application

Engine accessory gearbox powers:
- Hydraulic pump (flight control actuation)
- Fuel pump (fuel flow control)
- Oil pump (lubrication)
- Generator (electrical power)

**Typical specification:**
- Power: 5-50 kW
- Speed ratio: 1:3 to 1:8 (gearbox reduction)
- Material: Aluminum (housing), Steel (gears/shafts)
- Efficiency: 92-96%
